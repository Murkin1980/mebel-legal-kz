# Импорт архива мебельной компании

Пилотный импорт принимает ZIP до 25 МБ и не пытается угадывать назначение файлов.
В корне архива обязателен UTF-8 файл `manifest.csv`.

## Колонки manifest.csv

| Колонка | Назначение |
|---|---|
| `order_number` | Уникальный номер заказа |
| `customer_name` | Клиент |
| `project_title` | Изделие или проект |
| `amount_kzt` | Сумма в тенге |
| `document_type` | `invoice`, `act`, `contract` или `other` |
| `document_number` | Номер документа; для `other` можно оставить пустым |
| `file_path` | Точный путь файла внутри ZIP |
| `production_due_date` | `YYYY-MM-DD` или пусто |
| `delivery_due_date` | `YYYY-MM-DD` или пусто |

Один заказ может занимать несколько строк — по строке на каждый файл. Перед записью
система показывает предпросмотр. Архив сохраняется в закрытом Supabase Storage bucket,
повторный импорт того же SHA-256 не создаёт дублей.

Ограничения: максимум 500 файлов и 100 МБ после распаковки. Пути `../` запрещены.
В пилоте содержимое сканов не распознаётся автоматически.
